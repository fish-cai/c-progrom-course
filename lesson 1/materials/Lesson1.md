## 数据类型

| 数据类型 (Type)                          | 常见字节数        | 常见取值范围                            | 格式说明符 (printf/scanf)            | 核心作用与典型场景                                       | 代码示例                                |

| **`unsigned int`**                       | 4                 | 0 ~ 42.9亿 (0 ~ 2^32-1)                 | `%u`                                 | 无符号整数。用于表示绝对不可能为负的量（如长度、大小）。 | `unsigned int len = 500;`               |
| **`long`** (长整型)                      | 4 (Win) 8 (Linux) | 取决于系统                              | `%ld`                                | 跨平台大小不稳定，现代工程中**尽量少用**。               | `long id = 100000L;`                    |
| **`long long`**                          | 8                 | -922京 ~ 922京 (-2^63 ~ 2^63-1)         | `%lld`                               | 处理极大数值。如大数运算、高精度时间戳(毫秒/微秒)。      | `long long ms = 1700000000000LL;`       |

## 运算符

| 分类         | 运算符              | 名称                | 示例                | 核心作用与说明                                     | 教学避坑点 (Tips)                                          |
| :----------- | :------------------ | :------------------ | :------------------ | :------------------------------------------------- | :--------------------------------------------------------- |
| **算术**     | `+`                 | 加                  | `a + b`             | 两数相加                                           |                                                            |
|              | `-`                 | 减                  | `a - b`             | 两数相减                                           |                                                            |
|              | `*`                 | 乘                  | `a * b`             | 两数相乘                                           |                                                            |
|              | `/`                 | 除                  | `a / b`             | 两数相除                                           | ⚠️ **整数除以整数，结果自动向下取整**（直接砍掉小数）。     |
|              | `%`                 | 取模 (取余)         | `a % b`             | 求 a 除以 b 的余数                                 | ⚠️ **两边必须都是整数**，不能出现 `5.0 % 2`。               |
| **自增自减** | `++`                | 自增                | `i++` 或 `++i`      | 让变量自身的值加 1                                 | ⚠️ **前缀（`++i`）先加后用；后缀（`i++`）先用后加**。       |
|              | `--`                | 自减                | `i--` 或 `--i`      | 让变量自身的值减 1                                 | 同上。                                                     |
| **赋值**     | `=`                 | 赋值                | `a = 5`             | 把右边的值赋给左边                                 | 连续赋值：`a = b = c = 1;` (从右往左执行)                  |
|              | `+=`, `-=`, `*=` 等 | 复合赋值            | `a += 2`            | 等价于 `a = a + 2`                                 | 工程中常用，简化代码，有时能提高执行效率。                 |
| **关系**     | `>`                 | 大于                | `a > b`             | 判断是否大于                                       | 关系运算符的结果只有两种：**`1`（真）或 `0`（假）**。      |
|              | `<`                 | 小于                | `a < b`             | 判断是否小于                                       |                                                            |
|              | `>=` / `<=`         | 大于等于 / 小于等于 | `a >= b`            | 判断大小关系                                       |                                                            |
|              | `==`                | 等于                | `a == b`            | 判断两边是否相等                                   | ⚠️ **千万别写成 `=`**，这是 C 语言最致命的错误！            |
|              | `!=`                | 不等于              | `a != b`            | 判断两边是否不相等                                 |                                                            |
| **逻辑**     | `&&`                | 逻辑与 (AND)        | `a > 0 && b > 0`    | **两个都为真**，结果才为真                         | **短路特性**：如果左边为假，右边直接不执行。               |
|              | `||`                | 逻辑或 (OR)         | `a > 0 || b > 0`    | **只要有一个为真**，结果就为真                     | **短路特性**：如果左边为真，右边直接不执行。               |
|              | `!`                 | 逻辑非 (NOT)        | `!a`                | 真变假，假变真                                     | 常用于翻转布尔值，如 `!is_ready`                           |
| **其他**     | `? :`               | 三目运算符          | `a > b ? a : b`     | 唯一的三元运算符，可替代简单的 `if-else`           | 相当于：如果 `a>b` 为真，返回 `a`；否则返回 `b`。          |
|              | `sizeof`            | 长度运算符          | `sizeof(int)`       | 求数据类型或变量占用的字节数                       | 它是**运算符**，不是函数。括号里放类型，或者放变量都可以。 |
|              | `,`                 | 逗号运算符          | `int a = 1, b = 2;` | 从左到右依次执行，整个表达式的值是**最后一个**的值 | 优先级最低，日常开发中极少用它来拼接表达式。               |

## Sum 1-n

```c
#include <stdio.h>
int main(int argc, char const *argv[])
{
    int sum = 0;
    int i;
    int n;   // 定义变量n，用来接收用户输入

    printf("请输入整数n：");
    scanf("%d", &n);   // 从控制台读取数字存入n，&不能丢！

    for(i = 0; i <= n; i++){
        sum = sum + i;
    }
    printf("%d\n", sum);  // 补上分号
    return 0;
}

```

## Fibonnaci

```c
#include <stdio.h>
int main(void)
{
    int n1 = 0,n2=1,n3,number;
    for(int i=2;i<10;i++)
    {
        n3 = n1 + n2;
        printf("%d\n",n3);
        n1 = n2;
        n2 = n3;
    }
}
```
