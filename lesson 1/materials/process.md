| 分类            | 关键字 / 语句 | 语法示例                     | 核心作用                                       | 教学避坑点 (Tips)                                            |
| :-------------- | :------------ | :--------------------------- | :--------------------------------------------- | :----------------------------------------------------------- |
| **分支 (选择)** | `if` / `else` | `if(a>0) {...} else {...}`   | 根据条件决定走哪条路                           | 只要 `if` 或 `else` 后面超过一句代码，**必须加大括号 `{}`**。 |
|                 | `else if`     | `if(a>0){} else if(a<0){}`   | 多条件连续判断                                 | 从上往下依次判断，一旦命中一个，后面的全部跳过。             |
|                 | `switch`      | `switch(x) { case 1: ... }`  | 多分支等值判断（电梯直达）                     | ⚠️ **括号里只能是整型、字符型或枚举**，不能是浮点数（`float`）或字符串。 |
| **循环**        | `for`         | `for(int i=0; i<10; i++)`    | 已知循环次数时首选，最常用                     | 执行顺序：初始化 -> 判断 -> 循环体 -> 自增 -> 判断...        |
|                 | `while`       | `while(a < 10) { a++; }`     | 先判断，再执行。可能一次都不执行               | 条件不满足，循环体直接跳过。容易忘写条件更新导致死循环。     |
|                 | `do...while`  | `do { a++; } while(a < 10);` | 先执行，再判断。至少执行一次                   | ⚠️ `while` 后面**必须加分号 `;`**，这是最容易漏的。           |
| **跳转**        | `break`       | `break;`                     | **强行砸碎**并跳出当前所在的循环或 `switch`    | 在多层嵌套循环中，只跳出**最内层**的那一层。                 |
|                 | `continue`    | `continue;`                  | **跳过本次**循环的剩余代码，直接进入下一次循环 | 只结束当前这一圈，不结束整个循环。                           |
|                 | `goto`        | `goto label;`                | 无条件跳转到代码的指定标签处                   | ⚠️ **工程中极度不推荐**，会破坏代码结构（变成“意大利面条”），但在内核代码中常用于统一报错处理。 |
|                 | `return`      | `return 0;`                  | 结束当前函数，并返回一个值                     | 在 `main` 函数中执行 `return` 等于结束整个程序。             |
