### 指针、结构体与位运算符

| 分类       | 运算符 | 名称         | 示例            | 核心作用与说明                             | 教学避坑点 (Tips)                                    |
| :--------- | :----- | :----------- | :-------------- | :----------------------------------------- | :--------------------------------------------------- |
| **指针**   | `&`    | **取地址符** | `int *p = &a;`  | 获取变量在内存中的**门牌号**（地址）       | ⚠️ 只有变量能取地址，常量（如 `&5`）不能取。          |
|            | `*`    | **解引用符** | `*p = 10;`      | 顺着门牌号找过去，**操作**那个地址里的数据 | ⚠️ 这个 `*` 和乘法 `*` 是同一个符号，**看语境区分**。 |
| **结构体** | `.`    | 成员访问     | `stu.age = 18;` | 访问结构体变量里的成员                     | 专门用于“实体”（普通变量）。                         |
|            | `->`   | 指针成员访问 | `p->age = 18;`  | 通过指针访问结构体成员                     | 专门用于“指针”。等价于 `(*p).age`                    |
| **位运算** | `&`    | 按位与       | `a & b`         | 两个二进制位**都为 1** 才是 1              | ⚠️ **别和逻辑与 `&&` 搞混**，这是逐位比较。           |
|            | `|`    | 按位或       | `a | b`         | 两个二进制位**有一个为 1** 就是 1          | ⚠️ 别和逻辑或 `||` 搞混。                             |
|            | `^`    | 按位异或     | `a ^ b`         | 两位**相同为 0，不同为 1**                 | 常用于加密、交换两个变量（不用临时变量）。           |
|            | `~`    | 按位取反     | `~a`            | 0 变 1，1 变 0                             | 单目运算符。                                         |
|            | `<<`   | 左移         | `a << 1`        | 二进制向左移动，相当于**乘 2**             | 左移 1 位乘 2，右移 1 位除以 2（速度比乘除快）。     |
|            | `>>`   | 右移         | `a >> 1`        | 二进制向右移动，相当于**除以 2**           |                                                      |
