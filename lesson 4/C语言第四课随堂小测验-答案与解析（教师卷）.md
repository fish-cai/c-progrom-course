## 一、单选题（每题 8 分，共 40 分）

**1. 答案：A**
- 考察：do-while 与 while 的本质区别
- 解析：`do-while` 先执行循环体再判断条件，所以**至少执行一次**；`while` 先判断，条件不成立可能 0 次。循环次数不一定更多（条件一样时只多跑一次或相同），与整数无关。
- 讲评要点：一句话记牢——"do-while 至少跑一遍"。

**2. 答案：B**
- 考察：do-while "先执行后判断"
- 解析：`i = 10` 先进循环体，输出 1 个 `x`，`i` 变成 11；再判断 `11 < 5` 为假，退出。所以只输出 1 个。
- 讲评要点：把这道题和 `while(i < 5)` 版本的"输出 0 个"并排板书，对比最直观。

**3. 答案：B**
- 考察：do-while 结尾必须有分号
- 解析：`do{...}while(条件);` 结尾的分号是语句结束符，必须写。A 漏分号；C 在 `do` 块后多了分号，`while` 变成孤立的语句；D 语法完全错误。
- 讲评要点：本课第一高频错误，板书写三遍。

**4. 答案：B**
- 考察：do-while 执行流程
- 解析：先执行一次循环体 → 再判断 while 条件 → 条件为真回到循环体，为假跳出。
- 讲评要点：让学生画流程图，标清"先执行、后判断"。

**5. 答案：C**
- 考察：do-while 的适用场景
- 解析：输密码必须至少输入一次，输对才退出，正是"先做一次再判断"的典型；A、B 都是已知次数，适合 for；D 是典型 while 场景。
- 讲评要点：选型口诀——已知次数用 for，可能 0 次用 while，至少 1 次用 do-while。

## 二、填空题（每题 6 分，共 30 分）

**1. 分号 `;`**
- 解析：`do{...}while(条件);` 结尾必须有分号，否则编译报错。

**2. 1**
- 解析：`do-while` 先执行后判断，条件再假也先跑一遍，所以至少 1 次。

**3. 1**
- 解析：`n = 0` 时进循环体 `count++`（1 位），`n = 0/10 = 0`，判断 `n != 0` 为假退出，结果 1 位。这正是 do-while 相比 while 的优势。

**4. 执行循环体；判断条件**
- 解析：先执行一次循环体，再计算 while 条件。

**5. `3`**
- 解析：x 从 0 开始，循环体 `x++` 执行 3 次：x 变为 1、2、3；第 3 次后判断 `3 < 3` 为假退出，输出 3。

## 三、改错题（每题 4 分，共 20 分）

**1. 错误：`do-while` 结尾漏写分号**
- 修改：`}while(i < 5);`
- 解析：`while(条件)` 后面必须是分号，这是 do-while 特有的写法要求。

**2. 错误：循环体里没有改变 `i`，条件永远成立 → 死循环**
- 修改：在循环体里加 `i++;`
- 解析：循环体必须让条件趋向假，否则 `i < 5` 恒真，程序卡死。

**3. 错误：`while(n = 0)` 是赋值，不是判断相等**
- 修改：`}while(n == 0);`
- 解析：`n = 0` 先把 0 赋给 n，整个表达式值为 0（假），循环只执行一次就退出。判断相等必须用 `==`。

**4. 错误：累加器 `sum` 初值写成了 1**
- 修改：`int n = 5, sum = 0, i = 1;`
- 解析：求和累加器初值必须是 0；写 1 会让结果多 1（本题本应是 15，会算成 16）。

**5. 错误：循环条件写反，`n == 0` 应改为 `n != 0`**
- 修改：`}while(n != 0);`
- 解析：本意是"n 还没除完就继续"，应为 `n != 0`。写成 `n == 0` 时第一次判断就是假（12345/10=1234），只统计 1 位。

## 四、编程题（10 分）评分参考

**参考代码：**
```c
#include <stdio.h>

int main()
{
    int n, count = 0, sum = 0;
    scanf("%d", &n);              // 读取输入（1分）

    do
    {
        sum += n % 10;            // 取出最后一位并累加（3分）
        count++;                  // 位数 +1（2分）
        n = n / 10;               // 砍掉最后一位（2分）
    }while(n != 0);               // do-while 结构正确（2分）

    printf("位数：%d　数字和：%d\n", count, sum);   // 输出（1分）
    return 0;
}
```

**运行示例：**
```
输入：12345
输出：位数：5　数字和：15
```

**特殊情况：**
- 输入 `0`：`do-while` 先执行一次 → `sum += 0`，`count = 1`，输出"位数：1　数字和：0"，正确。

**评分点（共 10 分）：**
- 正确读取输入：1 分
- 用 `do-while` 结构（不是 while/for）：2 分
- 取最后一位 `n % 10` 正确：3 分
- 位数计数与 `n / 10` 更新正确：2 分
- 循环条件 `n != 0` 正确：1 分
- 输出格式清晰：1 分

**说明：**
- 学生若用 `while` 写但思路正确，本题按 6 分计（结构不符合题目要求）。
- 未处理 `n = 0` 也能得分，但可作为讲评的加分讨论点。
