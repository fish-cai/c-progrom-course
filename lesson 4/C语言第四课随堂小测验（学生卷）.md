## 一、单选题（每题 8 分，共 40 分）

1. `do-while` 和 `while` 最主要的区别是（　　）
   - A. `do-while` 的循环体至少执行一次
   - B. `do-while` 循环次数一定比 `while` 多
   - C. `while` 不需要判断条件
   - D. `do-while` 只能用于整数

2. 下面代码输出几个 `x`（　　）
   ```c
   int i = 10;
   do
   {
       printf("x");
       i++;
   }while(i < 5);
   ```
   - A. 0 个
   - B. 1 个
   - C. 5 个
   - D. 死循环

3. 下面 `do-while` 写法**正确**的是（　　）
   - A. `do { ... } while(x < 10)`
   - B. `do { ... } while(x < 10);`
   - C. `do { ... }; while(x < 10);`
   - D. `do while(x < 10) { ... };`

4. `do-while` 的执行流程是（　　）
   - A. 先判断条件，满足才执行循环体
   - B. 先执行一次循环体，再判断条件，决定是否继续
   - C. 先判断条件，再执行循环体，最后再判断一次
   - D. 条件一直为真，直到遇到分号

5. 下列场景中**最适合**用 `do-while` 的是（　　）
   - A. 已知循环 100 次求 1~100 的和
   - B. 遍历数组的前 10 个元素
   - C. 让用户输入密码，至少输入一次，输对才退出
   - D. 条件不满足就一次都不执行的场景

## 三、改错题（每题 4 分，共 20 分）

> 找出下面每段代码中的错误，写出错误原因，并给出修改后的代码。

1.
   ```c
   int main(){
       int i = 0;
       do {
           printf("%d", i);
           i++;
       }while(i < 5)
       return 0;
   }
   ```

2.
   ```c
   int i = 0;
   do {
       printf("%d", i);
   }while(i < 5);
   ```

3.
   ```c
   int n;
   do {
       scanf("%d", &n);
   }while(n = 0);
   ```

4.
   ```c
   int n = 5, sum = 1, i = 1;
   do {
       sum = sum + i;
       i++;
   }while(i <= n);
   ```

5.
   ```c
   int n = 12345, count = 0;
   do {
       count++;
       n = n / 10;
   }while(n == 0);
   ```

## 四、编程题（10 分）

题目：用 `do-while` 循环实现——输入一个正整数 `n`，输出它的**位数**和**各位数字之和**。

示例输入：`12345`
示例输出：`位数：5　数字和：15`

要求：
1. 必须使用 `do-while` 循环；
2. 用 `scanf` 读取 `n`；
3. 思考：`n = 0` 时你的程序输出什么？（位数应为 1，数字和应为 0）
