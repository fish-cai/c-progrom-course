## 📖 知识点清单

### 1. 三种循环回顾（承接第三课）

第三课重点讲了 `for`，这里把三种循环先摆在一起：

| 循环 | 语法骨架 | 判断时机 | 最少执行次数 | 典型场景 |
| --- | --- | --- | --- | --- |
| `for` | `for(初始化; 条件; 迭代)` | 先判断 | 0 次 | **已知循环次数**（求和、遍历） |
| `while` | `while(条件)` | 先判断 | 0 次 | 未知次数，满足条件才继续 |
| `do-while` | `do{...}while(条件);` | **先执行** | **1 次** | **先做一次，再决定要不要继续** |

> 一句话：`for` 和 `while` 都是"先看路况再上路"；`do-while` 是"先上车，再看要不要继续开"。

**复习提醒：** `for(;;)` 和 `while(1)` 都是死循环；`break` 跳出整个循环，`continue` 只跳过本轮。

---

### 2. while 复习：先判断，后执行（对照用）

```c
int i = 10;
while(i < 5)          // 一开始条件就不成立
{
    printf("执行了一次\n");
    i++;
}
// 结果：一次都不输出
```

**关键点：** 条件不成立时，`while` 的循环体**一次都不执行**。

---

### 3. do-while 语法与执行流程

```c
do
{
    循环体语句;
}while(表达式);      // ⚠️ 这里必须有分号！
```

**执行流程：**
1. **先执行一次循环体**
2. 再计算 `while` 后面的表达式
3. 如果为真（非 0）→ 回到第 1 步，再执行一轮
4. 如果为假（0）→ 跳出循环，继续往下走

**和上一段完全相同的条件，换成 do-while：**

```c
int i = 10;
do
{
    printf("执行了一次\n");   // 先执行了
    i++;
}while(i < 5);                // 再判断：10<5 不成立，退出
// 结果：输出一次
```

两个例子放在一起讲，学生一眼就能看懂差别：**同样的条件，while 输出 0 次，do-while 输出 1 次。**

---

### 4. while 与 do-while 对比（核心）

| 对比点 | while | do-while |
| --- | --- | --- |
| 判断时机 | 先判断，后执行 | **先执行，后判断** |
| 最少执行次数 | **0 次**（条件一上来就不成立） | **1 次**（无论如何先跑一遍） |
| 结尾写法 | `while(条件)` | `}while(条件);`，**必须有分号** |
| 适用场景 | 可能一次都不做 | 至少要做一次 |
| 常见翻车 | 忘写 `i++` → 死循环 | 忘写结尾分号 → 编译报错 |

**怎么选：**
- "先检查，合格才做" → `while`（比如：先查余额，够才取款）
- "先做一次，再问要不要继续" → `do-while`（比如：先输入一次，再问还输不输）

---

### 5. 【第一坑】do-while 结尾的分号

```c
// ❌ 错误：少了分号，编译直接报错
do
{
    printf("hello\n");
}while(0)

// ✅ 正确
do
{
    printf("hello\n");
}while(0);
```

**为什么容易漏：** 平时写 `while(条件)` 都不加分号，到了 `do-while` 结尾突然要加分号，习惯改不过来。

**记忆方法：** `do-while` 的 `while` 后面就是"整条语句的结尾"，语句结尾自然要有分号。

### 6. do-while 的典型使用场景（本课重点）

#### 场景一：菜单循环

菜单程序天生就是"先显示一次，再问要不要继续"：

```c
int choice;

do
{
    printf("\n===== 菜单 =====\n");
    printf("1. 开始  2. 设置  0. 退出\n");
    printf("请选择: ");
    scanf("%d", &choice);

    if(choice == 0)
    {
        printf("再见！\n");
    }
    else
    {
        printf("你选择了 %d\n", choice);
    }
}while(choice != 0);      // 选 0 才退出
```

#### 场景二：输入校验（不合格就重输）

```c
int score;

do
{
    printf("请输入 0~100 的分数: ");
    scanf("%d", &score);

    if(score < 0 || score > 100)
    {
        printf("输入不合法，请重新输入！\n");
    }
}while(score < 0 || score > 100);   // 一直循环到输入合法
```

> 对比：如果这里用 `while`，就得先让用户输入一次再进循环，需要重复写一遍 `scanf`；`do-while` 一次就够，代码更干净。

#### 场景三：处理"至少有一位"的数字

统计整数位数、数字反转，都天然适合 `do-while`——因为**任何整数至少有一位**（包括 0）：

```c
int n, count = 0;
n = 0;
do
{
    count++;          // 0 也有一位
    n = n / 10;
}while(n != 0);
// count = 1
```

如果用 `while(count)` 那种思路，`n = 0` 就会出错（一次都不执行，位数算成 0）。

### 7. do-while 里的 break 和 continue

规则和 `for`/`while` 里**完全一致**：

- `break`：立刻跳出整个 do-while（不再判断条件）
- `continue`：跳过本轮剩下的语句，**直接去判断 while 条件**

```c
int x, sum = 0;
do
{
    scanf("%d", &x);
    if(x < 0)
    {
        continue;       // 负数不要，跳过本次累加
    }
    sum += x;
}while(x != 0);
```

⚠️ 注意：`continue` 在 do-while 里会**跳到条件判断**，不会跳过条件判断；这一点和 while 一样。

### 8. 常见错误汇总（课堂重点强调）

1. **do-while 结尾漏分号**：`}while(条件)` 不加 `;` → 编译报错（本课第一高频）
2. **以为 do-while 也可能一次都不执行**：不会，至少一次
3. **循环体里忘了改变条件变量** → 死循环
4. **`while(条件)` 里写了赋值**：`while(x = 0)` 恒为假，只会执行一次，应写 `x == 0`
5. **`do` 后面直接跟变量声明**：C 标准里 `do` 后必须跟语句，要声明变量得先加大括号
6. **用 do-while 做"可能一次都不做"的事**：选错循环，逻辑会多跑一次（如"余额为 0 就跳过"的场景应优先 while）

### 9. 课堂对比：C vs Java 的 do-while

| 对比点 | Java | C |
| --- | --- | --- |
| 语法 | `do{...}while(cond);` | 完全一致 |
| 结尾分号 | 必须有 | **必须有** |
| 条件类型 | 必须 boolean | 任意表达式，非 0 为真 |
| 至少执行一次 | 是 | 是 |

> 结论：do-while 是三种循环里 C 和 Java 差别最小的，学生几乎可以无缝迁移，重点只需盯住"分号"和"条件是真假表达式"。
