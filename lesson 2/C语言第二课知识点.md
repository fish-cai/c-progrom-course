## 📖 知识点清单

### 1. 程序三大结构（概念）

- **顺序结构**：从上到下依次执行（之前的 HelloWorld、累加求和都是）
- **分支（选择）结构**：满足条件才执行某一段代码
- **循环结构**：重复执行（下节课内容，这里只预告一句）

> 一句话：顺序是一路走；分支是走到路口选一条路。

---

### 2. if 单分支

```c
if(表达式)
{
    语句块;
}
```

**重点：**
- 括号里是**表达式**，遵循 C 规则：**非 0 为真，0 为假**
- 只有一条语句时大括号可省略，但**教学上强制建议永远加大括号**（防止悬空 else、后续加代码出错）
- 语法和 Java 几乎一样，但 C 的 if 括号里可以是任意表达式（Java 必须 boolean）

**示例：判断是否成年**
```c
int age;
scanf("%d", &age);
if(age >= 18)
{
    printf("成年\n");
}
```

---

### 3. if-else 双分支

```c
if(表达式)
{
    // 条件成立时执行
}
else
{
    // 条件不成立时执行
}
```

**要点：** `else` 不能单独存在，必须依附 `if`。

---

### 4. if-else if 多分支（重点）

```c
if(条件1){

}
else if(条件2){

}
else if(条件3){

}
else{          // 可选，兜底分支

}
```

⚠️ **执行规则：** 从上往下依次判断，**只要一个条件成立**，执行对应代码后整个分支直接结束，后面不再判断。

**典型例题：分数评级**
- 90 及以上 → A
- 80~89 → B
- 60~79 → C
- 60 以下 → D

---

### 5.【难点】悬空 else（经典考题）

```c
int a = 1, b = 2;
if(a > 0)
    if(b > 0)
        printf("b>0");
else
    printf("else");
```

✅ **规则：`else` 永远和离它最近、还没有配对的 `if` 绑定。**

很多学生误以为 `else` 和第一个 `if` 配对，这是坑。
教学建议：**用大括号解决悬空 else，不要靠脑子猜配对。**

---

### 6. switch-case 分支

```c
switch(表达式)
{
    case 常量1:
        语句;
        break;
    case 常量2:
        语句;
        break;
    default:
        语句;
        break;
}
```

**重点清单：**
1. `switch` 括号内：**只能是整型 / char**，不能是 float、double【和 Java 一致】
2. `case` 后面：**必须是常量**，不能写变量、表达式
3. `break`：跳出 switch；**没有 break 会「case 穿透」**——本节课最大特色
   - 穿透有时可以有意利用（多个 case 执行同一套逻辑），但大多数时候是 bug
4. `default`：可选，所有 case 都不匹配时执行，位置不强制在最后（但推荐写最后）
5. 对比 if：**switch 适合离散等值判断**；**if 适合范围判断**（`>`、`<` 区间）

**case 穿透有意使用示例：**
```c
int month;
scanf("%d", &month);
switch(month)
{
    case 3:
    case 4:
    case 5:
        printf("春季");
        break;
    // ... 其他季节同理
}
```

---

### 7. 分支嵌套

- if 里面继续写 if，switch 里面嵌套 if
- 要点：**嵌套不要太深**，可读性变差；能用多分支 `if-else if` 就不要多层嵌套

---

### 8. 课堂对比：C vs Java 分支

| 对比点 | Java | C |
| --- | --- | --- |
| if 括号内 | 必须 boolean（true/false） | 任意表达式，0 假，非 0 真 |
| switch 支持类型 | int、char、enum、String（新版） | 只支持整型、char，不支持字符串 |
| case | 常量，break 规则类似 | 同样 case 穿透，规则一致 |

---

### 9. 常见错误汇总（课堂重点强调）

1. `if(a = 5)` —— 赋值代替 `==` 判断（第一课提过，分支里高频翻车）
2. `if` 条件后多加分号：`if(a > 0); { ... }` —— 分号是空语句，分支直接结束，大括号里的代码永远执行
3. `switch` 的 `case` 忘记 `break`，意外穿透
4. `case` 后面写变量、区间（如 `case n > 60:`）→ 语法错误
5. 省略大括号，后续新增代码导致逻辑错乱
6. 浮点数直接用 `==` 判断相等（先埋个坑，简单提一句，后面细讲）
