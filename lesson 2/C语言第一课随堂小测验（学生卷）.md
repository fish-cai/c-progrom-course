## 一、单选题（每题 8 分，共 40 分）

1. 关于 `#include`，下列说法**正确**的是（　　）
   - A. 和 Java 的 `import` 完全一样，用来导入类
   - B. 预处理阶段，把被包含头文件的文本复制到当前位置
   - C. 会自动链接库里面的函数二进制代码
   - D. 只能引入标准库，不能引入自己写的头文件

2. 以下代码的输出结果是（　　）
   ```c
   int a = 5;
   int b = 2;
   printf("%d", a / b);
   ```
   - A. 2.5
   - B. 2
   - C. 3
   - D. 2.0

3. 在 C 语言的判断条件里，代表“假”的值是（　　）
   - A. `false`
   - B. `0`
   - C. `-1`
   - D. 任意非 0 数字

4. 使用 `scanf` 读取一个 int 变量，写法**正确**的是（　　）
   - A. `scanf("%d", a);`
   - B. `scanf("%d", &a);`
   - C. `scanf(a, "%d");`
   - D. `scanf("%f", &a);`

5. 关于数组，下列说法**正确**的是（　　）
   - A. 定义数组时，方括号里的长度不能直接写普通变量
   - B. `int arr[5];` 数组下标范围是 1 ~ 5
   - C. 数组名可以直接用来赋值
   - D. 数组元素默认都是 1

## 四、编程题（10 分）

题目：输入一个正整数 `n`，输出斐波那契数列的前 `n` 项。

斐波那契规则：第 1 项 = 1，第 2 项 = 1，从第 3 项起每一项都等于前两项之和。

示例输入：`7`
示例输出：`1 1 2 3 5 8 13`

要求：
1. 使用 `for` 循环实现；
2. 使用 `scanf` 读取 `n`；
3. 数字之间用空格分隔。
