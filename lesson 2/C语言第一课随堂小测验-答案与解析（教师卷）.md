## 一、单选题（每题 8 分，共 40 分）

**1. 答案：B**
- 考察：`#include` 预处理原理
- 解析：`#include` 在预处理阶段把被包含头文件的**全部内容文本复制**到当前位置，本质是文本粘贴。Java 的 `import` 只起别名、不复制代码，二者并不一样；链接库函数二进制是**链接器**的工作，不是 `#include`；`#include` 也能引入自己写的头文件。
- 讲评要点：`#include` 复制的是"说明书"文本；真正把函数实现放进可执行文件的是链接阶段。

**2. 答案：B**
- 考察：整数除法
- 解析：`a`、`b` 都是 int，`5 / 2` 是**整数除法**，直接截断小数部分，结果为 `2`，不是 2.5。要得到 2.5 需写成 `(double)a / b` 或 `5.0 / 2`。
- 讲评要点：整数除以整数，结果还是整数，不四舍五入、只截断。

**3. 答案：B**
- 考察：C 语言的真假判定
- 解析：C 语言没有布尔类型，规则是 **0 代表假，任何非 0 值（含负数）代表真**。C 里没有 `false` 这个关键字。
- 讲评要点：这是和 Java（`true/false`）最大的区别之一，学生容易混。

**4. 答案：B**
- 考察：`scanf` 取地址符 `&`
- 解析：`scanf` 必须把读到的数据存进变量对应的内存地址，所以 int 变量前要写 `&a`，格式符用 `%d`。A 漏了 `&`；C 顺序写反；D 用 `%f` 是浮点格式符。
- 讲评要点：`scanf("%d", a)` 是最高频错误，漏 `&` 会崩溃或写不进数据。

**5. 答案：A**
- 考察：数组的基本性质
- 解析：定义数组时，方括号里的长度（容量）**不能直接写普通变量**。数组下标从 0 开始（`arr[5]` 合法下标是 0~4）；数组名不能直接赋值；数组元素默认值并不是 1（局部数组未初始化值是随机的）。
- 讲评要点：同类型 + 连续内存 + 下标从 0 开始；长度要常量，运行时不定长用动态内存。

## 二、填空题（每题 6 分，共 30 分）

**1. `main`**
- 解析：每个 C 程序有且只有一个 `main` 函数，程序从这里开始执行。

**2. `%d`**
- 解析：int 类型用 `%d` 输出，`%f` 用于浮点数。

**3. `sum + 10`**
- 解析：复合赋值 `sum += 10;` 等价于 `sum = sum + 10;`。

**4. 输出 `2`；执行完 `i` 的值是 `3`**
- 解析：`i++` 是后置自增，**先取 i 原来的值（2）参与输出**，输出后再自增，所以打印 2，之后 i 变成 3。

**5. `n % 2 != 0`（或 `n % 2 == 1`）**
- 解析：`n` 除以 2 的余数不为 0，说明是奇数。

## 三、改错题（每题 4 分，共 20 分）

**1. 错误：`scanf` 缺少取地址符 `&`**
- 修改：`scanf("%d", &a);`
- 解析：`scanf` 需要把数据写进变量地址，int 对应 `%d`，变量前必须加 `&`。

**2. 错误：`if` 条件里是赋值 `=`，不是相等判断 `==`，逻辑 bug**
- 修改：`if(a == 5){`
- 解析：`a = 5` 是给 a 赋值（结果恒为 5，非 0 恒真），达不到判断 a 是否等于 5 的目的。判断相等必须用 `==`。

**3. 错误：数组长度用了普通变量 `n`**
- 修改思路：改为固定长度数组，如 `int arr[100];`（运行时真正需要不定长时用动态内存分配，这里先用常量长度即可）
- 解析：定义数组时方括号里不能直接写普通变量，容量必须是编译期可知的常量。

**4. 错误：`main` 函数体缺少左大括号 `{`**
- 修改：`int main(){`
- 解析：函数体必须用 `{}` 括起来，少了左大括号会编译报错。

**5. 错误：`int` 类型不能用 `%f` 输出，格式符不匹配**
- 修改：`printf("%d", a);`
- 解析：`a` 是 int，输出要用 `%d`；`%f` 对应浮点类型。格式符必须和变量类型匹配，否则输出乱码。

## 四、编程题（10 分）评分参考

**参考代码：**
```c
#include <stdio.h>

int main()
{
    int n;
    scanf("%d", &n);          // 读取输入，记得 &（2分）

    int a = 1, b = 1;         // 前两项初始值（2分）

    for (int i = 1; i <= n; i++)
    {
        printf("%d ", a);     // 输出当前项（1分）
        int temp = a;         // 更新逻辑（3分）
        a = b;
        b = temp + b;
    }
    return 0;
}
```

**运行示例：**
```
输入：7
输出：1 1 2 3 5 8 13
```

**评分点（共 10 分）：**
- 正确读取输入 `scanf("%d", &n)`（含 `&`）：2 分
- 斐波那契初始值 `a=1, b=1` 设置正确：2 分
- `for` 循环边界 `i <= n` 正确（能输出前 n 项）：2 分
- 更新 `a`、`b` 的逻辑正确（下一项 = 前两项之和）：3 分
- 输出格式清晰（空格分隔，`printf("%d ", a)`）：1 分

**说明：**
- 允许学生写法略有差别（如用数组存储、用中间变量不同），只要输出结果符合样例即可给分。
- 迭代写法（不用数组）最简洁，适合第一课水平；若用数组也正确，不扣分。
