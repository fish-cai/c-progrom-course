## 📖 知识点清单

### 1. 为什么需要循环（概念引入）

- 顺序结构：从上到下走一遍
- 分支结构：走到路口选一条路
- **循环结构**：在某个路口绕圈，满足条件才继续往前走

> 一句话：循环就是"重复做同一件事，直到条件不满足"。

**生活类比：**
- 跑圈：绕操场跑 10 圈，每跑完一圈计数器 +1，跑到第 10 圈结束
- 等公交：一直等，直到公交车来了才上车

---

### 2. while 循环（先判断，后执行）

```c
while(表达式)
{
    循环体语句;
}
```

**执行流程：**
1. 计算括号里的表达式
2. 如果为真（非 0）→ 执行循环体
3. 执行完回到第 1 步，再次判断
4. 如果为假（0）→ 跳出循环，继续往下走

**重点：**
- 括号里是**表达式**，遵循 C 规则：**非 0 为真，0 为假**
- **先判断后执行**：如果一开始条件就不满足，循环体**一次都不会执行**
- 循环体内必须有**让条件趋向假**的语句，否则就是死循环

**示例：输出 1~5**
```c
int i = 1;
while(i <= 5)
{
    printf("%d\n", i);
    i++;       // 关键：让 i 趋向 6，否则死循环
}
```

⚠️ **高频翻车：** 忘了写 `i++`，条件永远成立 → 死循环，程序卡住。

---

### 3. do-while 循环（先执行，后判断）

```c
do
{
    循环体语句;
}while(表达式);
```

**与 while 的核心区别：**
- `while`：先判断，可能一次都不执行
- `do-while`：**先执行一次**，再判断，所以**至少执行一次**

**重点：**
- ⚠️ `while(表达式)` 后面**必须加分号 `;`**——这是最容易漏的
- 适用场景：需要先做一次操作再决定要不要继续（如菜单选择、输入校验）

**示例：菜单循环**
```c
int choice;
do
{
    printf("1.开始  2.设置  3.退出\n");
    printf("请选择:");
    scanf("%d", &choice);
    // 根据 choice 执行对应操作...
}while(choice != 3);   // 选3才退出，注意分号！
```

### 4. for 循环（重点中的重点）

```c
for(初始化表达式; 条件表达式; 迭代表达式)
{
    循环体语句;
}
```

**执行顺序（务必让学生背下来）：**
1. **初始化**（只执行一次，循环开始前）
2. **判断条件** → 假则跳出
3. **执行循环体**
4. **执行迭代表达式**（如 `i++`）
5. 回到第 2 步

**示例：求 1~100 的和**
```c
int sum = 0;
for(int i = 1; i <= 100; i++)
{
    sum = sum + i;
}
printf("%d\n", sum);   // 5050
```

**重点：**
- `for` 括号里的三部分用**分号**分隔（不是逗号）
- 初始化、条件、迭代**都可以省略**，但分号不能省
  - `for(;;)` → 死循环（等价于 `while(1)`）
- 初始化里可以定义变量（C99 支持），如 `for(int i = 0; ...)`

**省略写法（了解即可，教学上不推荐）：**
```c
int i = 0;
for(; i < 10; i++)   // 初始化已在外面做了
{
    printf("%d", i);
}
```

### 5. 三种循环对比与选用

| 对比点 | while | do-while | for |
| --- | --- | --- | --- |
| 判断时机 | 先判断后执行 | 先执行后判断 | 先判断后执行 |
| 最少执行次数 | 0 次 | 1 次 | 0 次 |
| 适用场景 | 未知循环次数 | 需要至少执行一次 | **已知循环次数** |
| 死循环风险 | 忘了更新条件 | 忘了更新条件 | 条件写错 |

**选用口诀：**
- 知道要循环几次 → **for**（首选，最清晰）
- 不知道几次，满足条件才停 → **while**
- 至少要做一次，做完再判断 → **do-while**

### 6. 循环嵌套（重点难点）

**概念：** 循环体里面再写循环。

**经典例题：九九乘法表**
```c
for(int i = 1; i <= 9; i++)        // 外层：行
{
    for(int j = 1; j <= i; j++)    // 内层：列
    {
        printf("%d×%d=%d\t", j, i, i*j);
    }
    printf("\n");                   // 一行结束换行
}
```

**执行逻辑：**
- 外层每走一步，内层从头跑到尾
- 外层跑 9 次，内层总共跑 1+2+3+...+9 = 45 次

⚠️ **教学要点：**
- 嵌套层数不要超过 3 层，否则可读性极差
- 内外层变量名不能重复（`i` 和 `j` 区分开）
- 画表格模拟执行过程，帮助学生理解

### 7. break 与 continue（核心考点）

| 关键字 | 作用 | 类比 |
| --- | --- | --- |
| `break` | **彻底跳出**当前整个循环 | 砸碎牢笼，直接走人 |
| `continue` | **跳过本次**循环剩余部分，直接进入下一次判断 | 这圈不跑了，直接跑下一圈 |

**重点区别：**
- `break`：循环**整个结束**，不再判断
- `continue`：只结束**当前这一圈**，回到条件判断，条件成立就继续下一圈

**示例：break——找到就停**
```c
// 在 1~100 里找第一个能被 7 整除的数
for(int i = 1; i <= 100; i++)
{
    if(i % 7 == 0)
    {
        printf("找到: %d\n", i);
        break;    // 找到了就跳出，不继续找了
    }
}
```

**示例：continue——跳过本次**
```c
// 输出 1~10 里的奇数（跳过偶数）
for(int i = 1; i <= 10; i++)
{
    if(i % 2 == 0)
    {
        continue;   // 偶数跳过，不执行下面的 printf
    }
    printf("%d\n", i);
}
```

⚠️ **高频考点：**
- `break` 在多层嵌套循环中，只跳出**最内层**那一层
- `continue` 只影响**当前所在层**的循环
- 和 Java 的 `break`/`continue` 行为一致

### 8. 死循环

**什么是死循环：** 条件永远为真，循环永远停不下来。

**常见写法：**
```c
while(1)        // 经典死循环
for(;;)         // 另一种死循环写法
```

**什么时候用死循环：**
- 主程序的事件循环（如游戏主循环）
- 配合 `break` 退出的菜单程序

**什么时候是 bug：**
- 循环体内忘了更新条件变量
- 条件写反了（如 `i > 10` 而不是 `i < 10`）

### 9. 课堂对比：C vs Java 循环

| 对比点 | Java | C |
| --- | --- | --- |
| `for` 语法 | `for(int i=0; i<10; i++)` | 完全一致 |
| `while` / `do-while` | 完全一致 | 完全一致 |
| `break` / `continue` | 完全一致 | 完全一致 |
| `for-each` 增强循环 | 有（遍历数组/集合） | **没有**，C 不支持 |
| 循环变量作用域 | `for(int i=...)` 的 i 只在循环内 | C99 起同样支持 |

> 结论：循环语法 C 和 Java **几乎一模一样**，学生有 Java 基础上手会很快。重点放在**循环嵌套**和**边界条件**上。

### 10. 常见错误汇总（课堂重点强调）

1. **死循环**：循环体内忘了更新条件变量（如 `i++` 漏写）
2. **差一错误**：循环边界写错，多一次或少一次
   - `i <= 10` vs `i < 10`，输出 10 个还是 9 个数？
3. **do-while 漏分号**：`while(表达式)` 后面忘了写 `;`
4. **for 括号里用逗号**：三部分之间必须用分号 `;`，不是逗号 `,`
5. **continue 后面的代码不执行**：学生误以为 continue 是"继续执行后面的代码"，实际是"跳过后面的，直接下一轮"
6. **嵌套循环变量重名**：内外层都用 `i`，内层修改影响外层
7. **浮点数做循环计数器**：`for(double d = 0; d < 1.0; d += 0.1)`——精度问题导致循环次数不对
